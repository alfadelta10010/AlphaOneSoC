Pazzy [LYNX], Role icon, tapeout — 10/4/25, 12:20 AM
I think this would be absolutely doable for your skills, given you even did a MIPS processor in VHDL! :praise: 

Unless the VHDL TT template has improved VHDL support, there are some catches to keep in mind. The reason is that the TT tools transpile every individual file to Verilog, preventing the use of package files or other external definitions, requiring basic std_logic or std_logic_vector ports and forcing old-school VHDL 1987 component/entity instantiation.

You can avoid these limitations by using the Verilog template and transpiling your VHDL files to a single Verilog file using GHDL.

toivoh [TT], Role icon, tested tapeout — 10/8/25, 9:50 AM
For my RAM emulator, there is the example project https://github.com/toivoh/tt09-pio-ram-emulator-example that shows how to use it.
The code includes the modules pio_ram_emu_transmitter and pio_ram_emu_transmitter in https://github.com/toivoh/tt09-pio-ram-emulator-example/blob/main/src/pio_ram_emulator.v / https://github.com/toivoh/tt09-pio-ram-emulator-example/blob/main/src/sb_io.v that can be used to interface to the RAM emulator.
For testing, there is https://github.com/toivoh/tt09-pio-ram-emulator-example/blob/main/test/pio_ram_emulator_model.v that tries to model the behavior of the RAM emulator, when it is connected as in https://github.com/toivoh/tt09-pio-ram-emulator-example/blob/cdd5c5701ea4d1b79aa99adb19441e2c5acbc164/test/tb.v#L72-L75. Try not to rely on the exact latency of the model, the receiver tells you when data is ready.
There is example code for testing the project on a Pico-Ice board with an ice40 FPGA and an rp2040 microcontroller in https://github.com/toivoh/tt09-pio-ram-emulator-example/tree/main/pico-ice
